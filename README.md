# TD-DFT Excited-State Pipeline

GPU-accelerated pipeline for modeling the excited-state electronic structure of organic
fluorophores with **PySCF / GPU4PySCF** and **ASE**. It goes from a single-point TD-DFT
calculation up to **excited-state ab initio molecular dynamics (AIMD)** in implicit solvent.

Example systems: **Coumarin 102** (ethanol) and **p-terphenyl** (cyclohexane).

> **Showcase version.** This repository contains the pipeline code and input geometries.
> Computed spectra and numerical results are intentionally not included.

---

## Pipeline overview

The pipeline is organized in three tiers of increasing physical realism. Each tier is a
chain of numbered Python scripts; every stage writes its output to a file that the next
stage reads, so a tier can be resumed from any completed step.

```
Tier 1  geometry ─► TD-DFT single point ─► vertical S1→S0 energy
Tier 2  S0 opt ─► S1 opt ─► numerical S1 Hessian ─► Wigner sampling ─► ensemble of vertical energies
Tier 3  S0 opt (PCM) ─► S1 opt (PCM) ─► Langevin AIMD on S1 (PCM) ─► trajectory sampling ─► ensemble
```

| Tier | Approach | Scripts |
|---|---|---|
| **1** | Single vertical S1→S0 energy at a fixed geometry; CPU vs. GPU validation | `src/tier1/00–03` |
| **2** | Nuclear Ensemble Approach (NEA): Wigner sampling around the S1 minimum from a numerical excited-state Hessian | `src/tier2/04–09` |
| **3** | Excited-state AIMD: Langevin dynamics on the S1 potential energy surface with implicit solvation, sampling geometries along the trajectory instead of from a harmonic distribution | `src/tier3/04, 06, 11–14` |

Shared utilities live in `src/common/`: molecule configuration, an ASE calculator wrapping
PySCF TD-DFT (energies and S1 gradients), geometry generation (RDKit), Gaussian broadening
and plotting, and radiative-rate estimation.

## Methods and design decisions

| Setting | Value | Notes |
|---|---|---|
| Functional | `wb97x-d3bj` | Range-separated hybrid with explicit D3(BJ) dispersion. `wb97x-d` is rejected by PySCF ≥ 2.14 as ambiguous between D3/D4 parametrizations. |
| Basis set | `6-31g*` | No diffuse functions. Reduced from `6-31+g*` after a smoke test on para-nitroaniline; kept identical across all stages. |
| Excited-state method | Full TDDFT | `mf.TDDFT(equilibrium_solvation=True)`, not the Tamm–Dancoff approximation. |
| Solvation | IEF-PCM | Equilibrium solvation, applied consistently at all four Tier 3 stages (S0 opt, S1 opt, AIMD, ensemble). |
| Excited states | `nstates = 5` | The S1–S2 gap is monitored during dynamics to flag possible state crossings. |
| Broadening | Gaussian | Default σ = 0.15 eV, configurable. |

All settings are centralized in [`src/common/molecule_config.py`](src/common/molecule_config.py)
so they cannot drift between molecules or pipeline stages.

## Installation

```bash
conda env create -f environment.yml
conda activate fluorescence
```

Key packages: `pyscf`, `gpu4pyscf-cuda12x` (or `-cuda11x`) with `cutensor`, `geometric`
(geometry optimization), `rdkit` (initial geometries), `ase` (Tier 3 dynamics), `numpy`,
`matplotlib`.

**GPU:** validated on an NVIDIA Ampere GPU with Python 3.10 and PySCF ≥ 2.14. GPU4PySCF does
not yet support the newest GPU architectures (e.g. Blackwell), so re-validate before running
on one.

## Usage

Each tier has a wrapper under `scripts/` that moves into `molecules/<name>/results/`, adds
`src/common` to `PYTHONPATH`, and runs the stages in order:

```bash
scripts/run_tier1.sh                      # Coumarin 102
scripts/run_tier2.sh                      # Coumarin 102
scripts/run_tier3.sh coumarin102 --gpu
scripts/run_tier3.sh p_terphenyl --gpu
```

To re-run a single stage, resume an interrupted MD run (`--resume`), or change parameters
(number of samples, σ, burn-in/production steps), call the numbered script directly from
the molecule's `results/` directory. Every script supports `--help`.

## Repository structure

```
├── environment.yml
├── src/
│   ├── common/      config, ASE/PySCF calculator, geometry generation, broadening
│   ├── tier1/       single vertical energy, CPU vs. GPU validation
│   ├── tier2/       Wigner / Nuclear Ensemble Approach
│   └── tier3/       excited-state AIMD with PCM
├── scripts/         run_tier1.sh, run_tier2.sh, run_tier3.sh
├── molecules/
│   ├── coumarin102/results/   input and S0-optimized geometries (.xyz)
│   └── p_terphenyl/results/   input and S0-optimized geometries (.xyz)
└── docs/
    └── tier3_theory_background.md   physical and theoretical background
```

Outputs generated by running the pipeline (logs, trajectories, spectra) are written to
`molecules/<name>/results/` and excluded from version control.
